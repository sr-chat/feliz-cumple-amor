# 🎉 ¡Feliz cumpleaños a mi amor Emi! ✨

Mini página web interactiva y responsiva creada especialmente para celebrar el cumpleaños de **Emi**, lista para publicarse en **GitHub Pages**.

---

## 📱 ¿Qué incluye?
- 💌 **Sobre animado interactivo:** Pantalla inicial tipo carta cerrada ("Para: Emi ✨ - De parte de tu novio esclavo") con sello de corazón.
- 🎊 **Efectos de Confeti:** Lluvia y cañones laterales de confeti al abrir la carta y al tocar el botón de confeti.
- 🎂 **Pastel interactivo:** Con velita encendida que se puede soplar al tocarla (¡pide un deseo con sonido mágico y lluvia de estrellas doradas!).
- 📜 **Mensaje personalizado:** *"¡Feliz cumpleaños a mi amor Emi! 🎉❤️"* con firma *"Tu novio esclavo ❤️"*.
- 🌙 **Recordatorio especial:** Botón interactivo de *"Las buenas noches"* con ventana emergente.
- 🎶 **Cajita de música (Web Audio API):** Melodía suave de "Feliz Cumpleaños" sintetizada nativamente en el navegador (sin archivos de audio externos ni enlaces caídos).
- 🌸 **Fondo dinámico:** Partículas flotantes de corazones, estrellas y flores.
- 📲 **Diseño 100% responsivo:** Optimizado para teléfonos móviles (iPhone y Android).
- 🔗 **Open Graph:** Vista previa configurada para que al mandar el enlace por WhatsApp se vea bonito.

---

## 🚀 Pasos para publicarla en GitHub Pages

### 1. Guardar cambios y subir el repositorio
```bash
git add .
git commit -m "Actualizacion: Feliz cumpleaños a mi amor Emi"
git push -u origin main
```

### 2. Activar GitHub Pages (Toma 30 segundos)
1. Ve a tu repositorio en GitHub: `https://github.com/sr-chat/feliz-cumple-amor/settings/pages`
2. En **Build and deployment** -> **Source**, selecciona `Deploy from a branch`.
3. En **Branch**, selecciona `main` y la carpeta `/ (root)`.
4. Haz clic en **Save**.

En 1 o 2 minutos, GitHub te dará el enlace público:
👉 `https://sr-chat.github.io/feliz-cumple-amor/`
