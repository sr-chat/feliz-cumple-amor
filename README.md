# 🎉 Página de Cumpleaños para Emi ✨

Mini página web interactiva y responsiva creada especialmente para celebrar el cumpleaños de **Emi**, lista para publicarse en **GitHub Pages**.

---

## 📱 ¿Qué incluye?
- 💌 **Sobre animado interactivo:** Pantalla inicial tipo carta cerrada ("Para Emi uwu - De: Tu Señor Chat") con sello de corazón.
- 🎊 **Efectos de Confeti:** Lluvia y cañones laterales de confeti al abrir la carta y al tocar el botón de confeti.
- 🎂 **Pastel interactivo:** Con velita encendida que se puede soplar al tocarla (¡pide un deseo con sonido mágico y lluvia de estrellas doradas!).
- 📜 **Mensaje personalizado:** El texto elegido con el tono auténtico de Héctor y firma *"Tu Señor Chat ❤️"*.
- 🌙 **Recordatorio especial:** Botón interactivo de *"Las buenas noches uwu"* con ventana emergente.
- 🎶 **Cajita de música (Web Audio API):** Melodía suave de "Feliz Cumpleaños" sintetizada nativamente en el navegador (sin archivos de audio externos ni riesgo de enlaces caídos).
- 🌸 **Fondo dinámico:** Partículas flotantes de corazones, estrellas y flores.
- 📲 **Diseño 100% responsivo:** Optimizado para verse increíble en teléfonos móviles (iPhone y Android).
- 🔗 **Open Graph:** Vista previa configurada con título e icono para que al mandar el enlace por WhatsApp se vea bonito.

## 🚀 Pasos para publicarla en GitHub Pages

### 1. Inicializar y subir el repositorio
Abre una terminal (PowerShell o Git Bash) en esta carpeta:
```bash
cd D:\Documents\GitHub\feliz-cumple-emi
git init
git add .
git commit -m "¡Feliz Cumpleaños Emi! 🎉"
git branch -M main
```

Crea un nuevo repositorio en tu cuenta de GitHub (por ejemplo llamado `feliz-cumple-emi` o el nombre que prefieras) y vincula el repositorio:
```bash
git remote add origin https://github.com/<TU_USUARIO>/feliz-cumple-emi.git
git push -u origin main
```

### 2. Activar GitHub Pages (Toma 30 segundos)
1. Ve a tu repositorio en GitHub desde el navegador: `https://github.com/<TU_USUARIO>/feliz-cumple-emi`
2. Haz clic en la pestaña **Settings** (Configuración) en la parte superior.
3. En el menú lateral izquierdo, haz clic en **Pages**.
4. En **Build and deployment** -> **Source**, selecciona `Deploy from a branch`.
5. En **Branch**, selecciona `main` y la carpeta `/ (root)`.
6. Haz clic en **Save**.

En 1 o 2 minutos, GitHub te dará el enlace público:
👉 `https://<TU_USUARIO>.github.io/feliz-cumple-emi/`

¡Y listo! Ya puedes copiar ese enlace y mandárselo a Emi por WhatsApp para que lo abra desde su teléfono. ❤️
